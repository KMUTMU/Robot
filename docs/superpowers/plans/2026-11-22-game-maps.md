# 주행 게임 개편 (실물 차 + 맵 6개) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 3D 차 모델을 11-22 사진과 맞추고, 게임을 맵 선택 구조로 바꿔 맵 6개(집·수집한 거실·거인의 책상·달 기지·볼링장·얼음 호수)를 넣는다.

**Architecture:** `game/src/game.js`를 `core.js`(렌더러·도우미) + `maps/*.js`(맵 정의, `MAPS.push({...})`) + `main.js`(차·물리·UI·`loadMap`)로 나누고 `build.py`가 한 IIFE로 이어 붙인다. `loadMap(id)`이 세계 전체를 갈아 끼운다. 물리에 공중(`py`,`vy`)과 옆 미끄러짐(`vl`)을 추가하되 기본값이면 기존과 동일.

**Tech Stack:** three.js r186 묶음(`window.THREE`, `window.THREEX`), 순수 JS, Python 빌드 스크립트, 확인은 Playwright + 시스템 Chrome(swiftshader).

**Spec:** `docs/superpowers/specs/2026-11-22-game-maps-design.md`

## Global Constraints
- 단위 mm, 좌표: x 오른쪽(동), z 아래(남), y 위. 차 진행 방향 = `(cos yaw, 0, -sin yaw)`.
- 화면 글자는 한국어, 해요체. 커밋 메시지 한국어, `main`에 직접 푸시, 강제 푸시 금지. 커밋 꼬리말 2줄(Co-Authored-By: Claude Fable 5.2, Claude-Session).
- 결과물: 저장소 맨 위 `RC카_주행게임.html`, `RC카_3D모델.html`(한 파일), `game/dist/`, `3d_model/dist/`(아티팩트용, git 제외). 한 파일 게임은 1.5MB 이하.
- 기본 물리값(`PH` 기본)에서 집 맵의 주행은 개편 전과 같아야 함: AI 한 바퀴 시간 ±2%, 충돌 0.
- 맵 정의에 없는 값은 기본값을 쓴다(맵 파일은 서로를 참조하지 않음).
- 비밀번호·핫스팟 이름 등은 어디에도 넣지 않음.

## Review Focus
1. 맵을 여러 번 오가며 바꿈(6회 이상) → 이전 맵의 메시·충돌체·소품·움직이는 것이 남지 않고 오류가 없어야 함 → Task 3 `test_switch_no_leftovers`.
2. 녹화·AI 모드·일시정지 중에 "시작 화면으로" 간 뒤 다른 맵 시작 → 기록·랩·모드가 초기화 → Task 3 `test_title_resets_state`.
3. 공중이거나 구멍·책상 아래로 떨어진 직후 F(되돌리기) → 경로 위 땅에 놓이고 `air=false`, 속도 0 → Task 4 `test_reset_while_airborne`.
4. 소품이 맵 밖이나 책상 아래로 밀려 나감 → NaN 없이 떨어져 멈춤 → Task 6 `test_prop_falls_off_desk`.
5. 모바일 가로(812×375)·좁은 창(900px 이하) 시작 화면 → 맵 카드가 가로로 스크롤되고 모드 버튼과 겹치지 않음 → Task 10 화면 캡처 확인.
