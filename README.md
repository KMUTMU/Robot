# 🤖 범블비 자동 변신 로봇 프로젝트

트랜스포머 범블비 스타일의 **소형 자동 변신 로봇**을 실제 부품으로 만드는 프로젝트예요.

## 🎯 목표
- ✅ 자동 변신 (버튼/앱 한 번에 자동차 → 로봇)
- ✅ 자동차 모드 주행
- ✅ 디테일 살아있는 정교한 외형
- ✅ 역동적 변신 (순차 + 회전)

## 🎬 변신 애니메이션 데모
`index.html` — 자동차 ⇄ 로봇 변신이 **순서대로 + 회전하며** 어떻게 보이는지 시각화한 데모.

GitHub Pages가 켜지면 아래 링크에서 바로 볼 수 있어요:
👉 **https://KMUTMU.github.io/Robot/**

### 역동적 변신의 3요소
| 애니메이션 요소 | 실제 로봇에서 | 설명 |
|----------------|---------------|------|
| 순서대로 접힘 (딜레이) | 서보 순차 실행 | 몸통 → 다리 → 팔 → 바퀴 → 머리 |
| 회전하며 펴짐 (rotate) | 서보 각도 회전 | 팔·머리가 돌면서 나오는 역동성 |
| 빨랐다 느렸다 (속도) | 서보 속도 조절 | "수동처럼" 생동감 있는 비결 |

## 🛠️ 준비물
전체 부품은 **[준비물_차수별.md](준비물_차수별.md)** 에 1·2·3차로 나눠 정리해뒀어요 (체크리스트).

### 1차 부품 (변신 두뇌 세트) — 주문 완료 ✅
| 부품 | 수량 | 용도 |
|------|------|------|
| ESP32 (CP2102, Type-C) | 1 | 두뇌 + 블루투스 제어 |
| MG90S 서보 (180도 메탈기어) | 3 | 힘 받는 변신 관절 |
| SG90 서보 (180도) | 2 | 가벼운 디테일 관절 |
| 브레드보드 + 점퍼선 + 전원모듈 키트 | 1 | 납땜 없이 배선 |
| 디지털 멀티미터 | 1 | 전압/단선 진단 |

- **2차** (전원+주행): 변신 코드 성공 후 구매 — 약 15만~25만 원
- **3차** (외형+조립): 변신 동선 확정 후 구매 — 약 15만~35만 원
