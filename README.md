# 🤖 범블비 자동 변신 로봇 프로젝트

트랜스포머 범블비 스타일의 **소형 자동 변신 로봇**을 실제 부품으로 만드는 프로젝트예요.

## 🎯 목표
- ✅ 자동 변신 (버튼/앱 한 번에 자동차 → 로봇)
- ✅ 자동차 모드 주행
- ✅ 디테일 살아있는 정교한 외형
- ✅ 역동적 변신 (순차 + 회전)

  - 현실 제약·치수·시퀀스 설명: [3d/설계_현실제약.md](3d/설계_현실제약.md)

### 역동적 변신의 3요소
| 애니메이션 요소 | 실제 로봇에서 | 설명 |
|----------------|---------------|------|
| 순서대로 접힘 (딜레이) | 서보 순차 실행 | 몸통 → 다리 → 팔 → 바퀴 → 머리 |
| 회전하며 펴짐 (rotate) | 서보 각도 회전 | 팔·머리가 돌면서 나오는 역동성 |
| 빨랐다 느렸다 (속도) | 서보 속도 조절 | "수동처럼" 생동감 있는 비결 |

| ESP32 (CP2102, Type-C) | 1 | 두뇌 + 블루투스 제어 |
| MG90S 서보 (180도 메탈기어) | 3 | 힘 받는 변신 관절 |

| 브레드보드 + 점퍼선 + 전원모듈 키트 | 1 | 납땜 없이 배선 |

- **2차** (전원+주행): 변신 코드 성공 후 구매 — 약 15만~25만 원
- **3차** (외형+조립): 변신 동선 확정 후 구매 — 약 15만~35만 원

### 블루투스 변신 버튼 사용법 (04번)
1. 코드 업로드 후 ESP32 전원 켜기
2. 안드로이드: **"Serial Bluetooth Terminal"** 앱 설치 (무료)
3. 핸드폰 블루투스 설정에서 **"Robot_Bumblebee"** 페어링
4. 앱에서 연결 → 글자 **'1'**(변신) / **'0'**(복귀) 전송
5. ⚠️ 아이폰은 클래식 블루투스 미지원 → BLE/WiFi 방식 필요

### 업로드 요령 (이 보드 필수!)
- 업로드 시 `Wrong boot mode` 에러 → **IO0(BOOT) 버튼 누른 채 업로드**
- "Connecting..." 뜰 때 IO0 꾹 → "Writing..." 뜨면 떼기
- Upload Speed는 115200 권장
