# 🏎️ 자율주행 RC카 프로젝트 (지도학습 기반)

시판 RC카(WPL C24-1)에 **카메라 + Raspberry Pi 5**를 올리고, **사람이 운전한 실주행 데이터로 지도학습**시켜
스스로 주행하게 만드는 프로젝트예요. (DonkeyCar 방식)

> 최종 업데이트: 2026-11-19 · 현재 단계: **카메라 설치·바닥 주행 테스트 완료 → 다음 작업은 트랙 만들기·데이터 수집**
>
> 🤖 **AI 에이전트·새 작업자는 [AGENTS.md](AGENTS.md)를 먼저 읽으세요.** (전체 구성·배선·값·현재 상태·다음 할 일 정리)

## 🎯 목표
- 시판 RC카 개조: 순정 수신 보드 대신 **Pi 5 + PCA9685 + 브러시드 ESC**로 조향·구동 제어
- **지도학습(Behavioral Cloning):** 카메라 이미지 → 조향·속도 예측
- 수동 주행으로 데이터 수집 → PC에서 학습 → 차가 스스로 주행
- 예산 20만 원 이내 (알리익스프레스 + 국내 스토어)
- 시뮬레이터는 생략: 우리 차 사양에 맞춘 실차 데이터로 학습

## 🧠 왜 지도학습(Behavioral Cloning)인가
입문 자율주행의 정석. "사람이 운전한 (이미지 → 조작) 쌍"을 그대로 흉내 내게 학습.
강화학습보다 **구현이 쉽고, 적은 데이터로도 트랙을 도는 결과**가 빨리 나와요.

```
[수동 주행] 카메라 이미지 + 내 조향/속도 기록
      ↓ 수천~수만 장
[학습]  CNN 모델: 이미지 → (조향, 속도)
      ↓
[자율주행] 차가 카메라만 보고 스스로 조향/속도 결정
```

## 🛠️ 하드웨어 (실제 구성)
| 역할 | 부품 | 상태 |
|------|------|------|
| 차 | WPL C24-1 RTR (1/16, 서보 비례 조향, 4WD) | ✅ 분해·보드 분석 완료 |
| 두뇌 | Raspberry Pi 5 1GB + 듀얼 쿨러 케이스 | ✅ OS·DonkeyCar 설치, 방열팬 연결 |
| 눈 | IMX219 8MP 160° 카메라 (Pi 5용 22핀 케이블) | ✅ 초점·장착·각도 완료 (180° 장착, 소프트웨어로 회전) |
| 조향 신호 | PCA9685 16채널 PWM (I2C 0x40) | ✅ 인식, 조향 서보 보정 완료 |
| 구동 | 브러시드 ESC 30A (2S, 전진·후진·브레이크) | ✅ 설치, 값 재측정 (앞 최대 330 / 정지 380 / 후진 최대 435) |
| 전원 | 2S 7.4V 배터리 → 스위치 → PCT-213 레버 단자대 → ESC + UBEC 5V 5A (UBEC는 서보 전원용, Pi는 USB-C → 보조배터리 예정) | ✅ 배선 완료 |
| 수동 조종 | 게임패드 MOGA XP5-X Plus (블루투스, 집에 있던 것) | ✅ 블루투스 페어링, 조종 확인 |

> 💡 분해해 보니 순정 보드(1039R-WPL)가 **수신기와 모터 드라이버 일체형**이라 PWM 입력이 없었어요.
> 그래서 모터용 브러시드 ESC를 새로 달고, 서보와 ESC 모두 PCA9685로 제어해요.

## 💻 소프트웨어 / 학습
- **Pi 5:** Raspberry Pi OS 64-bit (Trixie), Python 3.13.5, DonkeyCar 5.4.0, 프로젝트 `~/mycar`
- **PC(학습):** Windows 11 Pro, RTX 5060 Laptop GPU — 학습 환경은 데이터 수집 후 설치
- **추론 엔진:** Pi에 TensorFlow/TFLite 아직 없음 → 자율주행 직전에 설치
- 역할 분담: 데이터 수집·자율주행은 **차(Pi)**, 모델 학습은 **PC**

👉 데이터 수집 → 학습 → 배포 흐름: **[학습_파이프라인.md](학습_파이프라인.md)**
